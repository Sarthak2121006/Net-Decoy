# NetDecoy API Contract & Intelligence Specifications

This document outlines the contracts and schemas connecting the Deception Traps, Event Collector, Detection & Risk Engines, AI Explanation, Next-Stage Estimation, and the SOC Dashboard.

---

## 1. Event Ingestion (`POST /api/events`)

Each deception trap emits interactions conforming to `shared/event_schema.json`.

### Request Body
```json
{
  "event_id": "evt_001",
  "session_id": "sess_001",
  "timestamp": "2026-10-08T14:30:21Z",
  "source_ip": "192.168.1.105",
  "page": "login",
  "action": "failed_login",
  "event_type": "authentication",
  "payload": {
    "username": "admin"
  }
}
```

### Ingestion Response (`201 Created`)
```json
{
  "status": "success",
  "event_id": "evt_001",
  "detections": [
    {
      "attack_type": "BRUTE_FORCE",
      "detected": true,
      "severity": "HIGH",
      "evidence": [
        "5 failed login attempts observed within 60 seconds"
      ]
    }
  ]
}
```

## 2. Risk Score & Breakdown (`GET /api/risk?session_id=...`)

Calculated deterministically by `risk_engine.py`. Strictly bounded between `0` and `100`.

### Response
```json
{
  "session_id": "sess_001",
  "score": 87,
  "level": "CRITICAL",
  "breakdown": {
    "brute_force": 20,
    "scanning": 20,
    "sql_injection": 30,
    "sensitive_access": 17
  },
  "capped": false,
  "signals": [
    {
      "signal": "Brute Force Authentication",
      "points": 20,
      "reason": "Repeated failed login attempts (count: 5)"
    },
    {
      "signal": "Endpoint Scanning",
      "points": 20,
      "reason": "Probed 4 distinct endpoints (/login, /admin, /api, /database)"
    },
    {
      "signal": "SQL Injection Pattern",
      "points": 30,
      "reason": "Detected SQL auth bypass pattern (' OR '1'='1)"
    },
    {
      "signal": "Sensitive Resource Access",
      "points": 17,
      "reason": "Attempted download on decoy backup portal (/backup/db_dump.sql)"
    }
  ]
}
```

Severity Levels:
- `0–29`: `LOW`
- `30–59`: `MEDIUM`
- `60–79`: `HIGH`
- `80–100`: `CRITICAL`

## 4. AI Threat Analysis (`GET /api/analysis?session_id=...`)

Generated by `ai_engine.py` from structured evidence, with deterministic template fallback.

### Response
```json
{
  "session_id": "sess_001",
  "is_fallback": false,
  "summary": "Attacker initiated automated credential testing on the login portal, escalated through SQL injection in the database console, and concluded with an extraction attempt on confidential backup archives.",
  "likely_intent": "Account takeover followed by unauthorized database query execution and proprietary data exfiltration.",
  "evidence": [
    "5 failed login attempts within 60 seconds (BRUTE_FORCE)",
    "Pattern match for SQL injection auth bypass: ' OR '1'='1 (SQL_INJECTION)",
    "Direct GET request targeting sensitive backup decoy at /backup/customer_data_backup.sql (SENSITIVE_ACCESS)"
  ],
  "recommended_actions": [
    "Rate-limit or isolate IP 192.168.1.105 at the perimeter firewall",
    "Rotate synthetic credentials and inspect surrounding reverse proxy logs",
    "Maintain decoy monitoring to capture subsequent lateral movement attempts"
  ]
}
```

```json
  "current_stage": "CREDENTIAL_ACCESS",
  "next_stage": "PRIVILEGE_ESCALATION",

  "alternative_stages": [
    {
      "stage": "RESOURCE_DISCOVERY",
      "confidence": 20
    }

```

## 6. Unified Session Analysis (`GET /api/session/analysis?session_id=...`)

Generated by `pipeline.py` / `analyze_session()`, consolidating detection, risk, journey, prediction, and AI analysis into one payload.

### Response
```json
{
  "session_id": "sess_001",
  "event_count": 11,
  "detections": [],
  "detected_attack_types": [],
  "risk": {},
  "journey": {},
  "prediction": {},
  "ai_analysis": {},
  "processed_at": "2026-10-09T10:00:00Z"
}
```

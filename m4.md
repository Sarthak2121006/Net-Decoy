# NetDecoy --- M4 Deception Layer & Trap Engineer

## Role

You are **M4 --- Deception/Trap Engineer and Demo Flow Owner**.

Your job is to create six convincing but completely controlled fake
services/pages that attract simulated attacker interaction and generate
standardized events.

You also own the final attack demonstration sequence.

------------------------------------------------------------------------

# 1. Critical Rules

1.  Work primarily on the `traps` branch.
2.  Read `shared/event_schema.json` before implementing event
    generation.
3.  Do not modify backend event-storage logic.
4.  Do not build real vulnerable infrastructure.
5.  Do not expose real credentials or sensitive data.
6.  Never execute attacker-supplied SQL against a real database.
7.  Never allow path traversal to access the host filesystem.
8.  Keep all fake data synthetic.
9.  The pages should look realistic but remain controlled.
10. The six pages must generate events through the official event
    collector/API.

------------------------------------------------------------------------

# 9. Shared Event Contract

Every trap must send:

``` json
{
  "session_id": "sess_123",
  "page": "database",
  "action": "suspicious_query",
  "event_type": "sql_injection",
  "payload": {
    "pattern_detected": true
  }
}
```

The backend adds:

-   event ID
-   timestamp
-   source IP

if that is how the team's implementation is designed.

Do not create a second event schema.
